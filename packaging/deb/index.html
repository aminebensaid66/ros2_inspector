ros2inspector apt repository

Signed Ubuntu packages for ros2inspector, built for Ubuntu 22.04 (jammy), 24.04 (noble) and 26.04 (resolute) on amd64 and arm64. The package bundles its Python dependencies and does not need ROS 2 to be installed.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @REPO_URL@/ros2inspector-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/ros2inspector.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/ros2inspector.gpg] @REPO_URL@ $(. /etc/os-release && echo "$VERSION_CODENAME") main" \
  | sudo tee /etc/apt/sources.list.d/ros2inspector.list
sudo apt update
sudo apt install ros2inspector

Remove

sudo apt remove ros2inspector
sudo rm /etc/apt/sources.list.d/ros2inspector.list /etc/apt/keyrings/ros2inspector.gpg
